# HRanalysis — البنية الاساسية للمقاولات

نظام عربي لإدارة طلبات التوظيف والتدريب والتجربة والتقييم وتحليل مواءمة المرشحين.

## التشغيل
```bash
npm install
npm run dev
```
ثم افتح `http://localhost:3000`.

## المزايا الحالية
- إنشاء طلب متعدد الخطوات.
- أنواع توظيف جاهزة مع خيار أخرى.
- إضافة متطلبات وأوزان مجموعها 100%.
- إضافة المرشحين وتقييم كل متطلب من 0 إلى 100.
- حساب نسبة المواءمة النهائية تلقائياً وترتيب المرشحين.
- تقرير تفصيلي يوضح نقاط القوة والضعف والتوصية.
- حفظ محلي مؤقتاً عبر localStorage، مع schema جاهز لـ Supabase.
- واجهة RTL بألوان أزرق داكن وأصفر داكن وبدون شعار.

## Supabase
انسخ `.env.example` إلى `.env.local` وأضف بيانات مشروع Supabase، ثم نفّذ `supabase/schema.sql` في SQL Editor. الربط البرمجي الكامل يمكن تفعيله في المرحلة التالية دون تغيير نموذج البيانات.

## النشر على Vercel
اربط مستودع GitHub `tempo033/HRanalysis` بمشروع Vercel، وسيتم البناء باستخدام `npm run build`. لا توجد متغيرات بيئة مطلوبة لتشغيل النسخة المحلية الحالية.
